# Показательные скриншоты: известные программы Linux в HandTop

Дата: 2026-11-28. Статус: утверждено пользователем («все отлично» + съёмка и в классической теме,
окно HandTop в DeX развёрнуто, но не на весь экран).

## Зачем

Показать HandTop и его возможности: на телефоне в DeX работают те же известные программы, что на
обычном Linux-компьютере, в окнах рядом друг с другом. Скриншоты — для README и рассказа о проекте.

## Что снять

Пять сцен по 2–3 окна, с панелью задач HandTop, каждая в двух темах (Современная и Классическая) —
10 снимков:

1. **Разработка** — VS Code с исходниками HandTop, терминал (git, сборка), Firefox с документацией.
2. **Офис** — LibreOffice Writer с документом и Calc с таблицей и графиком.
3. **Графика** — GIMP 3 с фотографией и Inkscape с векторной картинкой.
4. **Мультимедиа** — Celluloid (mpv) с видео и Audacity со звуковой дорожкой. VLC отказывается
   работать от root («VLC is not supposed to be run as root»), а программы в HandTop — от root;
   подменять проверку ради снимка не стали.
5. **3D на GPU** — Blender 5 на Adreno (OpenGL 4.6 через Zink на Turnip) и терминал с `glxinfo -B`.

## Как снимать

- HandTop в DeX (монитор 1920×1080): окно развёрнуто во весь экран, но не в полноэкранный режим —
  нижняя панель DeX видна.
- Ubuntu 26.04 на телефоне. Firefox — из репозитория Mozilla (в Ubuntu он только через snap, snap
  в HandTop не работает); Thunderbird для arm64 нет — не снимаем. VS Code — пакет Microsoft.
- Содержимое делаю сам: документ и таблица про HandTop, код HandTop, свободный мультфильм
  Big Buck Bunny (Blender Foundation, CC BY 3.0) для плеера, его кадр — фото для GIMP, его звук —
  для Audacity. Файлов пользователя в кадре нет.
- Программы берут классическую тему при запуске: для второй серии тема переключается, программы
  перезапускаются.

## Как вышло (2026-11-28)

Снято 10 кадров (`docs/screenshots/programs/`), галерея добавлена в README. Всё установленное
удалено по журналу apt (419 пакетов, пробный прогон без лишнего), репозитории Mozilla и Microsoft
убраны, домашняя папка Linux совпадает со снимком до съёмки. Что всплыло по дороге — для HandTop:

- phantom process killer Android закрыл Firefox и VS Code (убил proot); помогло «Отключить
  ограничения дочерних процессов». Настройки HandTop читают `Settings.Global`, а переключатель
  пишет свойство `persist.sys.fflag.override.settings_enable_monitor_phantom_procs`.
- VLC не запускается от root.
- Окно GTK 4 с OpenGL под Wayland: «No EGL configuration available» (Celluloid); под X11 работает.
- Audacity со второго запуска: «unrecoverable error during startup», пока не удалить его настройки.
- Blender (X11, OpenGL): часть панелей не перерисовалась, пока окно не обновилось целиком.
- Смена темы сбрасывает положение и размер окон, терминал — размер шрифта.
