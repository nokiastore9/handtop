# Themes (Modern + Classic) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A theme mechanism for HandTop with two themes: Modern (today's look, the default) and Classic (gray bevelled 3D look, no transparency, shadows, blur or animations), switchable in Settings.

**Architecture:** `Palette` becomes a facade over `Themes.current` (a `Theme` object: colours, behaviour flags and drawable factories); every screen keeps calling `Palette.X` for colours and asks the theme for frames, buttons, menus, lists. Switching the theme saves it and `recreate()`s `DesktopActivity`, exactly like the interface-scale change. Classic visuals come from one `BevelDrawable` (raised / sunken / pressed / etched edges) plus a classic icon set chosen at runtime.

**Tech Stack:** Kotlin, Android views built in code (no XML layouts), vector drawables, JUnit 4 for JVM unit tests (new to the project).

**Spec:** `docs/superpowers/specs/2026-11-25-themes-design.md` (Russian; approved). Mockups: https://claude.ai/artifact/9Y7dgfsZSaZccC4Ubjrw4A (variant Б = "everything").

## Global Constraints

- minSdk 26; `RenderEffect` blur exists only on API 31+ and is never used by Classic.
- No Microsoft logos, pictures, icons or fonts, nor one-to-one redraws of them; the word "Windows" never appears in the UI. All classic icons are drawn by us.
- Theme names: en "Theme" / "Modern" / "Classic"; ru «Тема» / «Современная» / «Классическая». Wallpaper: en "Turquoise", ru «Бирюзовый».
- Default theme: Modern. Stored in SharedPreferences `"settings"`, key `"theme"`, values `"modern"` / `"classic"`.
- Classic colours (verbatim from the spec): face `#C0C0C0`; edge light `#FFFFFF`, inner light `#DFDFDF`; edge shadow `#808080`, dark shadow `#0A0A0A`; active title gradient `#000080` → `#1084D0` left to right, white bold text; inactive title `#808080` → `#B4B4B4`, text `#DFDFDF`; selection `#000080` with white text; fields and lists `#FFFFFF` with black text; text black; disabled text `#808080` with a 1 px white emboss.
- Classic has no rounded corners, no elevation shadows, no translucency, no blur, no animations.
- Touch sizes do not change in either theme: title bar `DesktopWindow.TITLE_HEIGHT_DP`, title buttons 44 dp wide, taskbar 48 dp, menu rows as today.
- Modern must look as before "by eye": colours, shapes and layout unchanged; small evening-out of text sizes/paddings from shared building blocks is allowed.
- A theme switch keeps exactly what a scale change keeps: terminals, Linux program windows, the Settings window (same page), the touchpad; file copies and the Linux install continue. Other HandTop windows close.
- Linux programs' own insides and their client-side title bars are out of scope.
- Every change ships for all devices, not Samsung-only. Code comments in English, explaining why, in the style of the surrounding code.

**Device check recipe** (used by every task; Git Bash on Windows, `MSYS_NO_PATHCONV=1`):

```bash
./gradlew -q assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start --display 0 -n org.handtop.desktop/.DesktopActivity   # always relaunch after install
adb exec-out screencap -p > shot.png                                     # then look at the screenshot
```

Never touch the phone's lock screen. Switch themes through Settings → Desktop → Theme (from Task 2 on).

## Review Focus

1. **Desktop icon labels in Classic**: `Palette.TEXT` turns black in Classic, but labels sit on the user's (usually dark) wallpaper; they must stay white with their shadow. Pinned in Task 8.
2. **Switching with a Linux program open** (xterm, a Wayland app): its window survives and its HandTop-drawn frame changes style. Pinned in Task 2 and Task 3 device checks.
3. **Other interface scales** (50 % and 150 %): bevel edges stay visible (at least 1 px each) and buttons stay touch-sized. Pinned in Task 3.
4. **Inactive and disabled states stay readable in Classic**: inactive title, minimized taskbar button, disabled menu item ("Restore HandTop's icons" when nothing is missing). Pinned in Tasks 3, 4 and 5.
5. **Leftover hard-coded colours**: a dark `0xFF…` surface missed in some screen makes Classic half-done. Pinned by the grep step in Task 11.
